# geo1729
GeoJSON data files for miscellaneous locations  

As of 2026-08-15, all of the files contained in this repo were originally obtained from the respective cities open data portals: 

Chicago: https://data.cityofchicago.org/ (multiple files) 
New York City: https://data.cityofnewyork.us/City-Government/2020-Neighborhood-Tabulation-Areas-NTAs-/9nt8-h7nd/about_data
Philadelphia: https://opendataphilly.org/datasets/philadelphia-neighborhoods/
Seattle: https://data-seattlecitygis.opendata.arcgis.com/datasets/SeattleCityGIS::neighborhood-map-atlas-neighborhoods
